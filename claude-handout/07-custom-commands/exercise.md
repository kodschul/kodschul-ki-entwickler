# Übung: Custom Commands

**Zeit:** ca. 30 min | **Projekt:** `1205/todo-app/`

---

## Aufgabe 1 – Review-Command erstellen (15 min)

Erstelle `.claude/commands/todo-review.md` nach dem Beispiel aus dem Handout und rufe ihn auf:

```
/todo-review
```

## Aufgabe 2 – Command mit Argument (15 min)

Erstelle `.claude/commands/add-feature.md` mit `$ARGUMENTS` und rufe ihn auf:

```
/add-feature Erinnerungen per E-Mail
```

Beobachte: Hält sich Claude an die Regel "erst Spec, dann Code"?
