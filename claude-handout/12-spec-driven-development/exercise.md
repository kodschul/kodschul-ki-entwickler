# Übung: Spec-Driven Development

**Zeit:** ca. 45 min | **Projekt:** `1205/todo-app/`

---

## Aufgabe 1 – Manuelle Spec schreiben (15 min)

```
Schreibe eine Spec unter specs/due-dates.md für das Feature
"Fälligkeitsdatum für Todos". Nutze die Vorlage aus dem Handout.
Warte auf meine Bestätigung, bevor du Code schreibst.
```

## Aufgabe 2 – Implementieren & testen (20 min)

```
Implementiere das Feature aus specs/due-dates.md. Halte dich genau an die Spec.
```

```
Schreibe Tests für das Due-Dates-Feature basierend auf den
Akzeptanzkriterien in specs/due-dates.md.
```

## Aufgabe 3 – Spec-Kit ausprobieren (10 min)

Wiederhole den Workflow mit dem eingebauten Spec-Kit für ein zweites, kleines Feature:

```

```

```

```
