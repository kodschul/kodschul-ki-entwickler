# Funktion 3: Das Angebot sieht aus wie ein echtes Dokument

## Was macht diese Funktion?

Das fertige Angebot wird nicht mehr als einfacher Text angezeigt, sondern sieht aus wie ein professionelles Geschäftsdokument — mit Kopfzeile, Abschnitten, Tabelle für Preise und Fußzeile.

---

## So sieht das Angebot aus:

- **Oben links:** Platz für dein Firmenlogo (optional)
- **Oben rechts:** Datum und Angebotsnummer
- **Empfänger:** Name und Firma des Kunden
- **Betreff:** Projektname, fett hervorgehoben
- **5 Abschnitte:** klar gegliedert mit Überschriften
- **Preistabelle:** Leistungen und Preise übersichtlich nebeneinander
- **Unten:** Gültigkeitsdatum des Angebots

---

## Als PDF speichern

Du brauchst keine extra Software. So geht's:

1. Das fertige Angebot wird angezeigt
2. Klicke auf den Button **„Als PDF speichern"**
3. Der Browser öffnet den Druckdialog
4. Bei „Ziel" wähle **„Als PDF speichern"**
5. Klicke auf **„Speichern"**

Das Ergebnis ist eine saubere A4-PDF-Datei, die du direkt an Kunden schicken kannst.
