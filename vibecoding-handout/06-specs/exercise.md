# Exercise: Specs - Was soll die App koennen?

## Ziel

Du beschreibst deine App-Anforderungen in verstaendlichen Geschichten.
Claude baut genau das, was du beschreibst.

---

## Aufgabe 1: Spec von Claude erstellen lassen

```text
Erstelle `.claude/specs/offer-flow-spec.md` fuer Offer Studio.
Schreibe 3 User Stories:
1. Als Vertriebsmitarbeiter moechte ich ein Angebot erstellen.
2. Als Reviewer moechte ich das Angebot pruefen lassen.
3. Als Vertriebsmitarbeiter moechte ich das Angebot uebersetzen.

Fuer jede Story: Wann ist sie erledigt? (mindestens 2 Kriterien)
Fuer jede Story: Was gehoert NICHT dazu?
Einen Fehlerfall pro Story einbauen.
```

---

## Aufgabe 2: Spec in eigenen Worten pruefen

Lies die Spec durch. Stelle sicher, dass du jeden Satz verstehst.
Wenn etwas unklar ist, bitte Claude:

```text
Dieser Abschnitt in der Spec ist mir unklar: [Zitat einfuegen].
Erklaere ihn in einem Satz und mache ihn verstaendlicher.
```

---

## Aufgabe 3: Eigene Story hinzufuegen

Denke an eine Funktion, die in der App noch fehlt.
Beschreibe sie als User Story:

```text
Fuege eine neue User Story zur Spec hinzu:
Als [wer] moechte ich [was], damit [warum].
Akzeptanzkriterien: [mindestens 2 Punkte]
Nicht dabei: [was gehoert nicht dazu]
```

---

## Aufgabe 4: Spec gegen App pruefen

```text
Vergleiche die Spec mit der bisherigen App.
Welche Stories sind bereits umgesetzt?
Welche fehlen noch?
Gib eine kurze Liste aus.
```

---

## Done-Kriterien

- [ ] Spec-Datei mit 3+ User Stories vorhanden
- [ ] Akzeptanzkriterien klar und verstaendlich
- [ ] Eigene Story hinzugefuegt
- [ ] Spec gegen App verglichen
