# Exercise - 06 Specs

## Aufgabe

Schreibe eine minimale, aber praxistaugliche Spec mit:

- 3 User Stories
- je 3 Akzeptanzkriterien
- 2 Fehlerfaellen

## Prompt fuer TN

```text
Erstelle fuer Offer Studio eine Spec mit:
- Story: Angebot erzeugen
- Story: Angebot reviewen
- Story: Angebot uebersetzen
Ergaenze Akzeptanzkriterien in Given/When/Then-Form.
```

## Done-Kriterien

- [ ] Spec-Datei vorhanden
- [ ] Stories sind testbar
- [ ] Kriterien sind eindeutig
