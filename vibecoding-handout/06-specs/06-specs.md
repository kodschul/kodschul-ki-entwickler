# 06 - Specs

## Ziel

Specs machen Anforderungen testbar und umsetzbar.

## Inhalte der Offer-Flow-Spec

- Nutzerfluss: Form -> Generate -> Review -> Translate -> Export
- Pflichtvalidierungen pro Feld
- Akzeptanzkriterien fuer Angebotsqualitaet
- Fehlerfaelle (fehlende Daten, ungueltiges Budget)

## Sample Prompt

```text
Erstelle `.claude/specs/offer-flow-spec.md` mit User Stories,
Akzeptanzkriterien und Negativfaellen fuer Offer Studio.
```

## Ergebnis

Team kann zielgerichtet entwickeln und sauber pruefen.
