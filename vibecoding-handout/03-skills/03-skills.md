# 03 - Skills

## Ziel

Skills kapseln wiederverwendbare Regeln fuer die Angebots-App.

## Relevante Skills fuer Offer Studio

- `offer-structure.md`: Pflichtgliederung fuer jedes Angebot
- `pricing-rules.md`: Richtlinien fuer Preisabschnitte
- `language-style.md`: Schreibstil fuer C-Level Lesbarkeit

## Sample Prompt

```text
Erstelle einen Skill `offer-structure.md` in `.claude/skills/`.
Der Skill soll immer diese Angebotsabschnitte erzwingen:
Executive Summary, Scope, Timeline, Pricing, Next Steps.
```

## Ergebnis

Claude kann stabile Angebotsqualitaet auch bei wechselnden Inputs liefern.
