# Exercise: 01 - Referenzen anwenden

## Ziel

Du setzt die ersten Claude-Prompts fuer die Frontend-Angebots-App um.

## Aufgabe 1: Erste Projektstruktur erzeugen

Fuehre diesen Prompt aus:

```text
Erstelle die Projektstruktur fuer eine Frontend-App "Offer Studio".
Lege an: frontend/src/pages, frontend/src/components, frontend/src/services,
CLAUDE.md, README.md, sample-inputs/rfp-basic.md und .claude Unterordner.
```

## Aufgabe 2: Basis-UI beschreiben

Fuehre diesen Prompt aus:

```text
Erzeuge eine einfache UI-Struktur mit:
- OfferForm
- OfferPreview
- GenerateButton
Beschreibe pro Komponente Aufgabe, Inputs, Outputs.
```

## Aufgabe 3: Prompt-Qualitaet vergleichen

Teste beide Prompts und vergleiche das Ergebnis:

```text
Erstelle ein Angebot.
```

```text
Erstelle aus den Formfeldern Kunde, Scope, Budget, Timeline einen Angebotsentwurf
mit den Abschnitten Executive Summary, Scope, Timeline, Pricing, Next Steps.
Sprache: Deutsch, Ton: professionell.
```

## Abgabe

- Kurze Notiz: Welche Prompt-Version war besser und warum?
- Liste mit 3 Verbesserungen fuer den finalen Prompt.
