# 05 - Agents

## Ziel

Agents teilen komplexe Angebotsarbeit in spezialisierte Rollen auf.

## Agenten fuer Offer Studio

- `compliance-reviewer.md`
- `quality-reviewer.md`
- `translator.md`

## Sample Prompt

```text
Erstelle `.claude/agents/compliance-reviewer.md`.
Aufgabe: Pruefe Angebotsentwurf auf Datenschutz, riskante Aussagen,
fehlende Haftungshinweise und markiere Risiken mit Prioritaet.
```

## Ergebnis

Mehr Qualitaet durch klare Verantwortung pro Agent.
