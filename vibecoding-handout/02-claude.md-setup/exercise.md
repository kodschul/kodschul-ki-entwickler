# Exercise: CLAUDE.md Setup

## Ziel

Du erstellst eine belastbare `CLAUDE.md`, die den Frontend-Flow inhaltlich steuert.

## Aufgabe 1: CLAUDE.md anlegen

Muster-Prompt:

```text
Erstelle `CLAUDE.md` fuer Offer Studio.
Pflicht: Produktziel, Angebotsstruktur, Tonalitaet, Compliance, UI-Flow.
```

## Aufgabe 2: Qualität pruefen

Muster-Prompt:

```text
Pruefe die CLAUDE.md auf Unklarheiten.
Nenne maximal 8 konkrete Verbesserungen mit Prioritaet.
```

## Aufgabe 3: Sample Input erzeugen

Muster-Prompt:

```text
Erstelle `sample-inputs/rfp-basic.md` mit den Feldern:
Kunde, Herausforderung, Scope, Budget, Timeline, Risiken.
```

## Aufgabe 4: End-to-End Test

Muster-Prompt:

```text
Nutze `CLAUDE.md` und `sample-inputs/rfp-basic.md`.
Erzeuge einen Angebotsentwurf mit den 5 Pflichtabschnitten.
Gib danach eine Selbstpruefung aus: Welche Regeln wurden eingehalten?
```

## Abgabe

- finale `CLAUDE.md`
- `sample-inputs/rfp-basic.md`
- 1 Testausgabe mit Selbstpruefung

## Done-Kriterien

- [ ] `CLAUDE.md` vorhanden und konsistent
- [ ] Sample Input vorhanden
- [ ] Testausgabe folgt den Regeln
