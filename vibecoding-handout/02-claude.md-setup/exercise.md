# Exercise - 02 CLAUDE.md Setup

## Ziel

Du erstellst eine `CLAUDE.md`, die direkt fuer die Frontend-Angebots-App funktioniert.

## Aufgabe 1: Datei anlegen

Prompt:

```text
Erstelle `CLAUDE.md` fuer das Projekt Offer Studio.
Enthalten sein muessen: Produktziel, Pflichtstruktur fuer Angebote,
Tonalitaet, Compliance-Regeln und UI-Flow.
```

## Aufgabe 2: Sample Input erzeugen

Prompt:

```text
Erstelle `sample-inputs/rfp-basic.md` mit Feldern:
Kunde, Herausforderung, Scope, Budget, Timeline.
```

## Aufgabe 3: Ersten End-to-End Test ausfuehren

Prompt:

```text
Nutze `CLAUDE.md` und `sample-inputs/rfp-basic.md`.
Erzeuge einen Angebotsentwurf mit den 5 Pflichtabschnitten.
```

## Done-Kriterien

- [ ] `CLAUDE.md` vorhanden und klar strukturiert
- [ ] Sample Input vorhanden
- [ ] Angebotsentwurf folgt den Regeln
