# Exercise: 00 - Deine erste App beschreiben

## Ziel

Du beschreibst deine App-Idee in natuerlicher Sprache - ohne Code.
Claude setzt sie um. Du beobachtest, was passiert.

---

## Aufgabe 1: App-Idee formulieren

Beantworte diese Fragen in eigenen Worten:

```
Meine App heisst: ___________________________
Sie hilft dabei: ___________________________
Die wichtigste Funktion ist: _______________
Wer nutzt sie: _____________________________
```

---

## Aufgabe 2: Erste App mit Claude starten

Oeffne Claude Code und schreibe genau das:

```text
Baue mir eine einfache Web-App mit dem Namen "Offer Studio".
Die App hat eine Startseite mit einem Formular.
Das Formular hat Felder fuer: Kundenname, Firma, Projektbeschreibung, Budget.
Unten gibt es einen Button "Angebot erstellen".
Wenn ich auf den Button klicke, soll eine Bestaetigungsmeldung erscheinen.
```

Claude baut die App. Du wartest.

---

## Aufgabe 3: Iteration - etwas verbessern

Schau dir das Ergebnis an. Was gefaellt dir nicht?
Beschreibe es Claude in einem Satz:

```text
Beispiele:
- "Mache den Button groesser und aendere die Farbe auf Dunkelblau."
- "Die Felder sollen nebeneinander sein, nicht untereinander."
- "Fuge ein Pflichtfeld fuer die E-Mail-Adresse hinzu."
```

Schreibe deine eigene Verbesserung:

```
Meine Verbesserung: _________________________________
```

---

## Aufgabe 4: Prompt-Qualitaet erleben

Vergleiche diese zwei Prompts selbst:

**Prompt A (zu vage):**

```text
Mach die App besser.
```

**Prompt B (konkret):**

```text
Fuge oben in der App eine Navigationsleiste hinzu mit den Links
"Neues Angebot", "Meine Angebote" und "Einstellungen".
```

Sende beide an Claude und notiere den Unterschied:

```
Prompt A ergab: ____________________________________
Prompt B ergab: ____________________________________
```

---

## Done-Kriterien

- [ ] App-Idee in eigenen Worten beschrieben
- [ ] Erste App von Claude gebaut
- [ ] Mindestens eine Verbesserung beschrieben und umgesetzt
- [ ] Unterschied zwischen vagem und praezisem Prompt erlebt
