# 04 - Commands

## Ziel

Commands machen wiederkehrende Schritte als Slash-Befehle nutzbar.

## Kern-Commands

- `/generate-offer`: erzeugt Angebotsentwurf aus Formulardaten
- `/review-offer`: prueft Struktur und Lesbarkeit
- `/translate-offer`: erzeugt EN-Version

## Sample Prompt

```text
Erstelle einen Command `.claude/commands/generate-offer.md`.
Input: Kundendaten, Scope, Budget, Timeline.
Output: Angebotsentwurf in Markdown mit 5 Pflichtabschnitten.
```

## Ergebnis

Die Frontend-App kann konsistente Flows via klarer Commands ausloesen.
